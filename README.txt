LA VIE INTERNATIONAL HOSPITAL - WEBSITE DEMO

Files:
- index.html
- styles.css
- script.js

How to use:
1. Open index.html in a browser.
2. For hosting: upload all 3 files to any static web host (Netlify, Vercel, Cloudflare Pages, cPanel hosting, etc.).
3. The site supports Vietnamese / Lao / English.
4. Current appointment form is a demo and opens the default email app. It can later be connected to a backend, WhatsApp, Google Sheets, Supabase, or hospital CRM.
5. Some photos are loaded from public news-source URLs and require internet access. For production, replace with hospital-owned original images in a local /images folder.
